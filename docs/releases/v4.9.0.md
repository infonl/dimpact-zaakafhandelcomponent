# Release v4.9.0

**Released:** 2026-05-13

## What's Changed

**Full Changelog**: https://github.com/infonl/dimpact-zaakafhandelcomponent/compare/v4.8.0...v4.9.0

## Bug fixes

- **PR #5887**: Contact details filled in via Open Formulieren productaanvraag (e.g. a changed preferred email address) were incorrectly treated as zaak-specific contact details; this is now fixed.
- **PR #5947**: Sorting of dashboard cards "aan mij toegewezen zaken/taken" was broken; cards now subscribe to sort changes, reset pagination correctly, and use the correct backend sort field names.
- **PR #5959**: Email template variables starting with `{ZAAKDATA:` now display "Onbekend" when zaakdata is null (e.g. when `SendConfirmationEmail` is the first BPMN service task). The bevestiging (confirmation) indicator is also no longer shown for BPMN zaken.
- **PR #5928**: The "Document maken" button on a BPMN zaak no longer produces a "SmartDocuments disabled" error. The BPMN-specific document creation code path was merged with the CMMN path.

## New features and improvements

- **PR #5880**: Adds an `active` boolean field to the `Group` domain model and `RestGroup` REST DTO, reading the `active` Keycloak attribute so downstream consumers can distinguish active from inactive groups.
- **PR #5889**: All three group list endpoints now correctly set `active: false` for groups marked inactive in Keycloak, including the PABC behandelaar path which requires an extra Keycloak lookup.
- **PR #5924**: Completes the "Deactivate groups" feature: inactive groups are filtered out of all group list dropdowns (backend), and zaak/taak detail pages show an *(inactief)* indicator next to the group name when the assigned group is inactive. Cases assigned to an inactive group can still be saved without forced reassignment.
- **PR #5957**: The task details change form (taak-edit) group dropdown now shows an *(inactief)* label for inactive groups, consistent with the zaak-details-wijzigen dropdown.
- **PR #5866**: Adds a `SendConfirmationEmailDelegate` BPMN service task that automatically sends an acknowledgement-of-receipt email to a zaak's initiator when invoked from a BPMN process.
- **PR #5959**: Email variables show "Onbekend" when zaakdata is null, and the bevestiging indicator is suppressed for BPMN zaken.
- **PR #5918**: Adds two new formio field keys (`ZAC_smart_documents_template_groups` and `ZAC_smart_documents_template_group_templates`) that expose configured SmartDocuments template groups and templates for use in formio forms.
- **PR #5885**: Dashboard cards in the same row now share a uniform height, with a `ResizeObserver` keeping rows aligned as content loads at different speeds.
- **PR #5808**: Adds a `StaticCacheFilter` that sets `Cache-Control: public, max-age=31536000, immutable` on Angular's content-hashed JS/CSS bundles, eliminating redundant re-downloads on every page load.
- **PR #5950**: Migrates `TakenWerkvoorraadComponent`, `ZakenWerkvoorraadComponent`, and `ZoekComponent` to Angular v19 standalone components as part of the ongoing Angular standalone migration.

## Documentation

- **PR #5879**: Adds documentation for the new `sendConfirmationEmailDelegate` to the BPMN manual.
- **PR #5922**: Adds documentation explaining how to use the new SmartDocuments formio template field keys (`ZAC_smart_documents_template_groups` and `ZAC_smart_documents_template_group_templates`).
