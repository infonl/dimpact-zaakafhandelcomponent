# Release v4.8.0

**Released:** 2026-04-29

## What's Changed

## Bug fixes

- **PR #5777**: Fixed wrong icon color regression in Angular v19 standalone migration — document/task list and TakenCard anchor buttons now use `MatIconAnchor` instead of `MatAnchor`, restoring the correct icon color.
- **PR #5772**: Changed the Kubernetes liveness probe to use the `/health/ready` endpoint to allow ZAC to automatically recover from an OpenZaak catalogus outage; the failure threshold is raised to 16 (approx. 480 s) so the pod restarts when the catalogus is unavailable for an extended period.
- **PR #5797**: Made the office-converter container port configurable via Helm values so it can be overridden (e.g. when using an alternative image such as `kontextwork-converter`); default remains `3000` for Gotenberg.
- **PR #5829**: Fixed an `IllegalStateException` that occurred when retrieving the logged-in user from an already-invalidated HTTP session, for example when a user logs out or their session times out while signaleringen are being sent.
- **PR #5845**: Fixed PABC container version numbers whose `v` prefix had been removed in the upstream repository, causing hash mismatches.
- **PR #5838**: Fixed a serialization bug in the `ExternAdviesMail` task form where the full `RestZaakAfzender` object was stored in `taakdata.verzender` instead of the mail string, causing a backend deserialization error on form submit.
- **PR #5825**: Fixed a timing issue in BPMN e2e tests where a dropdown could not be clicked before the form had finished loading; added wait conditions for task values to be present before interacting.
- **PR #5854**: Improved BPMN e2e test reliability by adding reload/retry helpers that recover from backend slowness, 502/503 responses, or empty Formio wrapper loads, and by tightening visibility and readiness checks across task, form, and document-signing steps.

## New features and improvements

- **PR #5766**: Added integration tests for BPMN productaanvraag processing; also fixed BPMN zaakafhandelparameters to use the group name instead of the description.
- **PR #5779**: Renamed SmartDocuments database tables to remove the `cmmn_` prefix (PZ-10703).
- **PR #5784**: Replaced the `kontextwork-converter` Docker image with `gotenberg` for office document conversion, updating all configuration, ports (8080 → 3000), and API paths to match Gotenberg's conventions.
- **PR #5785**: Implemented `ExternAdviesVastleggenTaskFields` as a new Angular-style task form, replacing the old ATOS form builder and adding 35 unit tests for field structure, validation, and i18n keys.
- **PR #5795**: Enabled SmartDocuments configuration and template mappings for BPMN zaaktypes, which previously only worked for CMMN; includes database migration, backend service changes, and a new frontend SmartDocuments form component.
- **PR #5813**: Added support for the 'Geen enkel entiteitstype' functional role from PABC by introducing `overallRoles` in `LoggedInUser` and applying it in the appropriate authorization checks.
- **PR #5810**: Lazy-loaded the Documenten and Productaanvragen Angular feature modules to reduce the initial app bundle load.
- **PR #5828**: Added support for building and using ARM64 Docker images locally by setting the `DOCKER_USE_ARM64_CONTAINERS` environment variable; images are maintained in the `infonl/dimpact-docker` repository.
- **PR #5835**: Preserved SmartDocuments template configurations when creating a new version of a BPMN zaaktype, preventing mappings from being lost on zaaktype version updates.
- **PR #5846**: Migrated the `EXTERN_ADVIES_MAIL` task form from the deprecated ATOS pattern to the new Angular injectable task form pattern.
- **PR #5861**: Load the default email address when available in the Advies External Email form.
