# Release v5.0.0

**Released:** 2026-05-26

## What's Changed

## New features and improvements

- **PR #6066**: Fixed and stabilized end-to-end tests.
- **PR #5951**: Fixed SmartDocuments group/template selection in Form.io: when `smartDocumentsGroupId` or `smartDocumentsTemplateId` is provided the sidebar now auto-selects and disables the matching group/template. Also removes the obsolete formio variable `ZAC_smart_documents_template`.
- **PR #5971**: Retrieves contact details for a rechtspersoon from Open Klant.
- **PR #5995**: Refactored notification integration tests for better maintainability.
- **PR #6012**: Changed the SOLR index to use a typed/prefixed betrokkene identification format (e.g. `P-<bsn>`, `K-<kvk>`, `V-<kvk>-<vestiging>`, `U-<username>`), and updated backend indexing, tests, and the Angular klant-zaken filter accordingly.
- **PR #6013**: Removed the obsolete `identificatie` property from bedrijf components and made the link to the detail page functional using vestigingsnummer and kvk nummer.
- **PR #6016**: Removed the PABC feature flag and all code and documentation related to the old IAM architecture.
- **PR #6024**: Deleted the `domein` field from the datamodel and codebase, including the DOMEIN reference table.
- **PR #6030**: Updated `renovate.json` to consolidate Docker image dependency groupings for upstream and mirrored images, reducing noise from multiple PRs for related images.
- **PR #6031**: Dashboard card tables now show a spinner instead of an empty-state message while data is loading on initial fetch.
- **PR #6033**: Removed the spotless version restriction from the Renovate config.
- **PR #6037**: Updated the allowed PodiumD versions list in the Helm chart configuration.
- **PR #6039**: Shows the full type name of a KVK bedrijf in the bedrijfsgegevens component.
- **PR #6045**: Refactored the "Zoekopdracht opslaan" dialog to use `zac-form-actions` and `zac-auto-complete` shared components, aligning it with the standard dialog pattern.
- **PR #6053**: Added the ability to retrieve the profile of a rechtspersoon in the bedrijfsgegevens and bedrijf-view components via a new endpoint.

## Bug fixes

- **PR #5960**: Fixed column sorting on the "Recent aan mij toegewezen taken" and "Mijn binnenkort verlopende zaken" dashboard cards. The root cause was a race condition where `MatSort`/`MatPaginator` wiring ran before `ngAfterViewInit` resolved the `@ViewChild` refs; moving the wiring to `ngAfterViewInit` guarantees the refs are populated.
- **PR #5978**: Fixed column sorting on the remaining two dashboard cards ("Recent aan mij toegewezen zaken" and "Mijn zaken met recent toegevoegde documenten"), including renaming a mis-bound Documenttype column so its value actually displays.
- **PR #6009**: Suppressed dashboard card height synchronisation while cards are still loading data to prevent visual jittering on initial render.
- **PR #6049**: Fixed automatic receipt sending for authenticated product requests that have product-specific contact details.
- **PR #6061**: Restored the toolbar exit button in the "Zoekopdracht opslaan" dialog.
- **PR #6063**: Filtered out preferred addresses from request-specific klantcontact lookups to prevent incorrect zaak-specific contact details being used, and added an integration test covering the saved preferred address scenario.
- **PR #6064**: Fixed the Open Formulieren Docker Compose setup.
- **PR #6067**: Added `zaakSpecificContactDetails` to the `zac-static-text` component in bedrijfsgegevens.

## Documentation

- **PR #6062**: Updated user manuals, including removal of documentation related to the old IAM setup (PZ-11144).
