# Release v4.7.2

**Released:** 2026-05-28

## What's Changed

This is a patch release containing only the changes listed in the sections below.

## Bug fixes

- **PR #6073**: Fixed mail template creation failing due to JSON deserialization error. The root cause was that ngx-editor auto-detects output format from the first `writeValue` call; when creating a new template the initial empty value was converted to null, causing the editor to output ProseMirror JSON doc objects instead of HTML strings. HTML output format support was added to the html-editor component and tests were extended accordingly.
